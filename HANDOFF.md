## Built
- Sync (Move tab, bottom card, :378 markup; module :2242–:2383): a secret GitHub Gist file sf-move-sync.json {state, device, savedAt} is the store. Every save() diffs the flattened state against the last snapshot and stamps meta.touched[path] (dotted leaf paths; id-arrays such as spend.entries.<id> and customTasks.<card>.<id>; a touched path with no leaf is a tombstone). save() = user write with Date.now(); saveSeed()/init-time writes stamp 0; first run stamps an established store "now" and a fresh install 0 (meta.stamped). Merge (mergeRemote :2263): per leaf the newer stamp wins, a side that knows nothing keeps the other, ties keep local; if the gist is behind this device (lost write race) the pull marks it dirty and re-pushes. Pull on load / visible / every 60 s with If-None-Match; push 2 s after a change, always pull+merge first; offline or failed → queued with 2 s→60 s backoff; 401/403 stops retries until Connect is pressed again. trip.tracking, spend.openDay, spend.nowDay are per-device and never merged.
- Responsive from 700px (one @media block at the end of the stylesheet, :341): .wrap 1040px, the five card containers become repeat(auto-fit,minmax(380px,1fr)) grids (two columns on an 820px iPad, 380 not 420 because 2×420+16 needs 856px of content), text blocks capped at 70ch, tab bar centred in 600px, Trip hero full width with max-height 70vh via preserveAspectRatio slice (vb() :1734 reports the cropped visible box to the zoom/pan maths).
